Featured Project

STATIZ KBO win-probability prediction system.

An end-to-end forecasting pipeline for the 1st STATIZ KBO Outcome Prediction Competition, from live data collection to daily API submission.

I built a system that predicts home-team win probability for KBO regular-season games, generates features from live and historical baseball data, trains an ensemble model, and submits daily predictions through the competition API.

Read Project PDF More Projects
  1. 01

    Collect reliable inputs

    Pull schedule, lineup, team, pitcher, and game context data through signed STATIZ API calls.

  2. 02

    Build leakage-safe features

    Create home-minus-away differences such as lineup OPS gap, starter quality, bullpen fatigue, and park interactions.

  3. 03

    Train an ensemble

    Combine RandomForest and ElasticNet logistic regression, validated with expanding-window backtesting.

  4. 04

    Submit and monitor

    Run the deployed pipeline on AWS EC2 with an HTML dashboard for per-game prediction review.
